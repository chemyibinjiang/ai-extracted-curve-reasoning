# Analysis Archive

`analysis_before_effective_bv_20260927.zip` preserves the superseded analysis
entry points, fixed-coefficient-sum fits, five-family alkaline reconstruction,
parameterization comparisons, supporting inputs, and their regression tests.
It also preserves the earlier `figures/Figure_05_bvir/` and
`figures/Figure_06_ptc_relative/` calculations and their exported figures.
`MANIFEST.json` records the archive and member SHA-256 hashes.

This is a historical snapshot, not a manuscript reproduction entry point.
Archive paths retain their repository-relative names. Inspect or unpack them
in a separate directory; do not unpack over the current checkout.

The current workflow is [analysis/effective_bv/](../../analysis/effective_bv/).
It requires neither this archive nor the investigation transcripts. Shared
numerical functions that it still uses remain in `analysis/` and are tested
without the archive present.
