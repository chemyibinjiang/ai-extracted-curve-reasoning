# Literature Extracted-Curve Data

This folder contains the Zenodo-ready extracted literature HER curve dataset:

- `zenodo_extracted_curve_dataset_v1/`
- `zenodo_extracted_curve_dataset_v1.zip`

`build_zenodo_extracted_curve_dataset.py` records the packaging logic used to
generate the release from the internal canonical publication database. The
canonical source tables and original publisher assets are not included in this
public repository; the generated public dataset is included here directly.
