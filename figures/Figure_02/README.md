# Figure 2 Workflow Source

Figure 2 was assembled from the HTML/SVG workflow material in:

`figures/Figure_02/workflow_html_svg`

The folder contains the generated workflow figure assets and the scripts used to
assemble them. The workflow uses one concrete source-grounded HER example
(`batch0/case3`, Figure 4a, DOI 10.1002/adma.202400433) to illustrate the
multi-stage extraction process.

Original publisher figure/source-HTML asset folders are not included in this
public repository draft. The generated manuscript-facing figure outputs are kept
here for traceability.
