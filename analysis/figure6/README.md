# Figure 6: Pt/C families, VHT reconstruction, and rate control

Install `requirements-analysis.txt` from the repository root. No plots, source
PDFs, external archives, or network access are needed for these calculations.

## Commands

```text
python analysis/figure6/run.py
python analysis/figure6/run.py discover --output build/figure6-discovery
python analysis/figure6/run.py refit --workers 4 --output build/figure6-refit
```

Each output directory is independent. Use a new directory when changing inputs
or code; the original discovery cache deliberately rejects a mismatched hash.
`FIGURE6_OUTPUT` or `--output` changes the destination. Inputs are never overwritten.

| Stage | Computation | Deliberately fixed |
| --- | --- | --- |
| `replay` (default) | Reprofile empirical current scales on original points, verify family assignment, reconstruct VHT templates, recalibrate each curve's current amplitude, recompute coverage and all rate controls, means/SD/support/crossings | Published empirical templates and selected kinetic parameters |
| `discover` | Full candidate-grid profiling and maximum-coverage MILP for K=1..10 separately in each electrolyte | Input points, windows, threshold and original search protocol |
| `refit` | Original seeded multistart VHT optimization, followed by KOH kinetic-dimension search | Published empirical library; this stage is not initialized from new `discover` outputs |
| `controls` | Repeat rate-control calculation and reference-table checks after `replay` | Kinetic parameters generated by `replay` |

`refit` preserves the original model-selection comparisons, including residual-R
and alternative KOH parameter-sharing models. It can be substantially slower than
replay and may select a different, nearly equivalent representative. It does not
update frozen reference results or artwork. Do not run the published `controls`
regression check on new optima and interpret a mismatch as a numerical defect.

## Files and panels

- `empirical.py`, `vendor/empirical/`: curve eligibility, linear-class screening,
  empirical BV+jR template search, assignments, coverage-versus-K (panel C), and
  BV-slope/Q coordinates (panel D).
- `kinetic.py`, `koh_kinetic.py`, `vendor/vht/`: VHT reconstruction of the family
  curves in A/B, fixed versus recalibrated raw-curve replay, effective kinetic
  coordinates (E), and coverage/flux predictions.
- `control_core.py`: reversible elementary-step perturbations, independent
  mass-action solver, and degree of rate control (F).
- `inputs/`: retained original digitized coordinates, source point indices, and
  curve/paper/electrolyte/DOI metadata. Coordinate extraction itself is not rerun.
- `reference/`: selected empirical libraries, expected assignments and coverage
  scans, published kinetic representatives, and the KOH search initialization.
  Computational K1-K5 labels correspond to plotted B1-B5.

Default outputs include per-curve/per-point predictions under `empirical/` and
`koh/`, `RATE_CONTROL_FAMILY_GRID.csv`, `RATE_CONTROL_MEAN_SD.csv`, and
`REPLAY_CHECKS.json`. The regression check compares regenerated curves against
`expected/`, independently rederiving the dominant-control crossings.

## Fixed scientific conventions

The original cohorts contain 81 acidic and 267 alkaline curves. Fixed windows
are 0-200 and 0-300 mV; at least five original points with nonzero voltage variance
are required. This leaves 78/263 eligible curves, of which 5/29 are adequately
through-origin linear. Thus nonlinear coverage denominators are **73 and 234**,
not 81/267 or 348. Four/five templates cover 59/73 and 195/234 at R2 >= 0.99.

Each K is independently optimized over a finite, data-independent candidate
grid. The libraries are not necessarily nested; count certification is not a
continuous-parameter global-optimality certificate. Every accepted original
point is retained for kinetic replay, with fixed family assignments and support.

The VHT models use detailed balance, steady-state V-H-2T=0, current V+H,
alphaV=alphaH=0.5 and no added resistance. Acid shares both rate ratios and varies
effective DeltaG/current amplitude by family. KOH shares H/V and varies DeltaG,
T/V and amplitude. These are effective representative parameters, not unique
mechanisms or per-curve posterior distributions. Acid's normalized T/V ordinate
is zero by construction, not an independently measured invariance.

Rate control perturbs a step's forward and reverse constants together, resolves
coverage, and preserves the absolute kV scale. Means weight families equally;
SD is sample SD (ddof=1), not a confidence interval. The drawn means use common
fitted support. Acid's mean has no dominant crossover, but **A4 has two**; KOH's
mean has two and every alkaline family crosses. This is model-conditioned rate
control redistribution, not proof of a universal rate-determining step or an
experimentally established pathway switch.

## Verification status

Default replay regenerated all 4,591 family-grid rows and 998 mean/SD rows and
verified 12 individual/mean dominant crossings. VHT raw-curve R2 passes are
48/59 (acid) and 174/195 (KOH); all 254 empirical-member curves remain included.
Full empirical discovery was also rerun: all 20 coverage counts and the selected
nine template indices/member counts agree with the supplied reference results.
The full VHT multistart optimization and KOH parameter-sharing search have also
been run with the pinned environment. The selected acid and KOH models recovered
the supplied parameters and per-family errors, with 48 and 174 raw-curve R2 passes.
`REFIT_CHECKS.json` records these comparisons for each refit. Agreement in one
environment is not a proof of uniqueness or global optimality.
